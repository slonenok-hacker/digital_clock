# Digital Clock Widget in Lazarus

Простой виджет цифровых часов с секундами на базе среды Lazarus (Object Pascal). Окно без рамок, размер автоматически подстраивается под выбранный шрифт.


> ⚠️ Это демонстрационный проект для обучения и портфолио. Не содержит внешних зависимостей.

## Особенности

- **Цифровые часы** — время берётся с ПК, обновляется каждую секунду.
- **Выбор шрифта** — через контекстное меню (правая кнопка мыши) открывается стандартный диалог выбора шрифта.
- **Адаптивный размер** — окно автоматически меняет размер под новый шрифт и блокируется от дальнейшего изменения.
- **Кроссплатформенность** — проект на Free Pascal, работает в Windows, Linux и macOS (при сборке в Lazarus).
